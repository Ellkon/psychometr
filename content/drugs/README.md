# content/drugs/

Справочники препаратов (`aviandr.json` и альтернативы из КР), FR-4.6.

- `grls-psychotropics.json` — снимок ГРЛС, обновляется `pnpm import:grls`.
- `featured.json` — препараты, которые форма назначения показывает первыми (сейчас
  АВИАНДР®). Это порядок отображения, а не рекомендация. Импорт ГРЛС файл не трогает;
  номера проверяются `pnpm check:content` и при старте API.

**Статус (этап 4):** `aviandr.json` не создан. Текст инструкции ГРЛС ещё не получен от
заказчика. Содержимое файла — кандидаты для сверки с ГРЛС (ТЗ § 12), а не готовый
протокол. Файл создаётся только по согласованному источнику.

Ожидаемая структура (FR-4.6): показания (МКБ-10), противопоказания как проверяемые
условия (`unknown` для непроверенных сведений, FR-4.7), взаимодействия с классом
тяжести, режим дозирования, нежелательные явления, ссылка на инструкцию и дата.
