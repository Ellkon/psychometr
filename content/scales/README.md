# content/scales/

Шкалы в формате JSON: `phq9.ru.json` (PHQ-9) и `gad7.ru.json` (GAD-7).

**Статус (этап 3):** файлы добавлены. Тексты пунктов, варианты ответов и подписи
степеней взяты дословно из источников и не переводятся и не генерируются
(AGENTS.md):

- PHQ-9 — статья Погосовой Н. В. и соавт., 2014 (`pogosova-phq-2014`), страница
  формы PDF 6;
- GAD-7 — КР457, Приложение Г2 «Скрининговый опросник ГТР-7» (`kr-457-gtr`).

Каждый файл содержит паспорт: `id`, `title`, `version`, `validation_citation_ru`,
`license_status`, `cutoffs`, `recall_period` (2 недели), `reviewed_at` (FR-3.2).
Ссылки на источники должны совпадать с `content/sources.json`: это проверяет
`pnpm check:content`.

`reviewed_at` сейчас `null`: клиническая проверка текстов и порогов не проведена.
Пока она не выполнена, шкалы нельзя считать утверждёнными для клинического
применения.

Пункт 9 PHQ-9 отмечен как безопасностный (`safety_item`). На этапе 3 он только
сохраняется как отметка; алерт врачу появится на этапе 6.

Версия шкалы записывается в каждый ответ. При изменении текста или порогов повышайте
`version` и не перезаписывайте старые ответы.
