# Текст согласия

Утверждённый ответственным за обработку ПДн текст сюда не придумывается.

Для подключения положите файл `approved.txt` (UTF-8) в эту директорию и задайте:

- `CONSENT_TEXT_PATH=/run/consent/approved.txt`
- `CONSENT_VERSION` — неизменяемый идентификатор версии документа.

Изменение текста требует новой версии. Сервер фиксирует версию, SHA-256 текста,
время и зашифрованный IP принятия. Без подключённого документа приглашение
нельзя активировать. Текстовые файлы в этой директории исключены из Git.

CI создаёт **только синтетическую заглушку**, не юридическое согласие. Она не
может использоваться для обработки данных настоящих пациентов.
